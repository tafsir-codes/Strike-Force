
# Strike Force

Strike Force is a single player 2D action-adventure game developed in C/C++ with iGraphics library.

Term Project, Software Development I [CSE 1200]

Department of Computer Science and Engineering
Ahsanullah University of Science and Technology, Bangladesh

## Installation

1.Download the Visual Studio 13. Link Below:
https://www.junian.dev/downloads/visual-studio/#download-visual-studio-2013

2.Download the Strike Force folder in zip format and unzip it.

3.Open with Visual Studio 13

[![Screenshot-2026-09-21-102713.png](https://i.postimg.cc/x1JsB6Gs/Screenshot-2026-09-21-102713.png)](https://postimg.cc/K1brMrHL)

4.This window will appear

[![Screenshot-2026-09-21-103405.png](https://i.postimg.cc/c1tBxvgz/Screenshot-2026-09-21-103405.png)](https://postimg.cc/yWBZnYTh)

5.Wait a few seconds.Then the game will run automatically.
